# Feast & Fun — Restaurant Reservation Website 🍽️

A responsive Flask restaurant website with table reservation requests, buffet packages, food menu cards, and a mini lucky-wheel game.

## Features
- Responsive restaurant landing page
- Menu cards with food photography
- Reservation request form
- Buffet package selector
- Lucky wheel mini-game
- Health endpoint (`/health`)
- Docker-ready

> Reservations are demo requests: this project does not save bookings to a database or send email. The demo confirmation is generated by the Flask API.

## Run locally with Python
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```
Open: http://localhost:5000

## Build and run with Docker
```bash
docker build -t feast-and-fun:v1 .
docker run -d --name feast-and-fun -p 8080:5000 feast-and-fun:v1
```
Open: `http://YOUR_SERVER_PUBLIC_IP:8080`

Check:
```bash
docker ps
docker logs feast-and-fun
curl http://localhost:8080/health
```

Stop/remove:
```bash
docker stop feast-and-fun
docker rm feast-and-fun
```

## Upload to GitHub
Create a new GitHub repository, then in this project folder:
```bash
git init
git add .
git commit -m "Initial Feast and Fun restaurant booking project"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/feast-and-fun-restaurant.git
git push -u origin main
```

## Deploy on EC2
1. Install Docker and make sure it is running.
2. Clone your GitHub repository.
3. In the EC2 security group, allow inbound TCP port `8080` from your desired source.
4. Build and run the Docker commands above.

## Note about photos
Food and venue photos are loaded from Unsplash via internet URLs. They need internet access in the visitor's browser. Replace the photo URLs in `templates/index.html` with your own images whenever you like.
